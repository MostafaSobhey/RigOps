Drilling Co-pilot

Rig-site question answering

A chat assistant for operational decisions on the rig floor. It routes a question to the right verified calculator, names the inputs that must be confirmed first, and declines to produce a number it cannot show working for — the calculation always comes from the audited engine, never from the model.

Built on The RigOps Field Suite calculation layer, covered by an automated formula test suite.
Analytics In development

Drilling Engineer Suite

Offset study & history analysis

Surfaces comparable offset wells for a planned trajectory, then reads their drilling history for performance trends, recurring trouble zones and non-productive time patterns — so the next well programme starts from what the field has already learned rather than from a blank page.

Built on Offset analysis, trajectory modelling and drilling-KPI practice with Petrel, Compass and WellView across Norpetco and Khalda operations.
Hybrid physics + ML Published research

Virtual Flow Meter

VFM for ESP-lifted wells

Estimates production rate without a physical multiphase meter by combining pump physics with a learned correction. Built to survive the move from single-well troubleshooting to robust field-wide deployment, which is where most virtual metering work breaks down.

Built on A Hybrid Physics-ML Framework for Virtual Flow Metering in ESP-Lifted Oil Fields
Predictive reliability Published research

ESP Failure Prediction

Run life & failure-type framework

Two problems in one model: how long the pump has left, and what is going to take it out. Run life is estimated with a neural network trained on ESP databases, workover records and DIFA reports; failure mode and root cause are separated through the two-step IFMRC classification rather than conflated as they usually are.

Built on Dual-Level ESP Failure Classification — Energies 2025 and the ANN run-life thesis, grounded in ESP field operations at Qarun.
